# esp32

Sketches for the **Waveshare ESP32-S3-Touch-AMOLED-1.64**.

## Apps

- [BouncingBalls](BouncingBalls/) — colorful balls bouncing off the screen edges
  and each other with elastic collisions.
- [WiFiDashboard](WiFiDashboard/) — local clock, current weather, and Wi-Fi
  connection status. Tap to refresh; configurable location and time zone.
- [Game2048](Game2048/) — swipe-controlled 2048 on a portrait 4×5 board.
- [HelloTom](HelloTom/) — two-screen touchscreen greeting demo.
- [SpiritLevel](SpiritLevel/) — bullseye spirit level using the onboard QMI8658
  IMU. Tap to tare, with roll/pitch readout and auto-zero on boot.
